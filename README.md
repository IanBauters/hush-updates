# Hush updates

Ready-made builds of **Hush**, a Navidrome player for Mac and Android. The apps check this
page for new versions and update themselves.

- `mac-<build>`: Hush for Mac (`Hush-mac-<build>.zip`)
- `android-<build>`: Hush for Android (`Hush-android-<build>.apk`)

The builds are made automatically from a private repository; this repository only holds the
downloads.
